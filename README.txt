Streaks PWA - hosting
1. Upload this whole folder (keep the structure) to any HTTPS static host:
   Netlify Drop, Cloudflare Pages, GitHub Pages, Vercel.
2. Open the URL on your phone.
   Android/Chrome: menu > Install app.
   iPhone/iPad (Safari): Share > Add to Home Screen, then open it from the Home Screen.
3. In the app: Settings > Reminders > Turn on notifications.
Files: index.html (app), sw.js (offline + notifications), remind.js (shared reminder logic),
manifest.webmanifest, icons/.
